IDIOMALAB - instalación rápida

1. Copia toda la carpeta "idiomas_app" dentro de:
   C:\xampp\htdocs\

2. Abre XAMPP y enciende:
   Apache
   MySQL

3. Entra a:
   http://localhost/phpmyadmin

4. Ve a Importar y selecciona:
   database.sql

5. Después abre:
   http://localhost/idiomas_app/

6. Crea una sección y agrega palabras.

NOTA:
La primera versión guarda las secciones y palabras en MySQL.
El progreso de cada prueba es temporal: al salir de una prueba vuelve a comenzar desde cero.
Más adelante podemos agregar usuarios y progreso permanente.
